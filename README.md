# Hijri Lock Style Widget

按截图做的极简 Android Widget，只显示：

19:21
Mon 28 September
(Rabi al-Thani 17)

- 24 小时制
- 英文公历日期
- 括号包住的伊斯兰历
- 透明背景
- 每分钟更新
- 支持横向/纵向调整大小

## 编译
这是一个标准 Android Studio/Gradle 项目。
也附带 GitHub Actions：上传到 GitHub 后运行 Actions -> Build APK，即可得到 app-debug.apk。

## 添加到桌面
安装 APK 后，在三星桌面长按 -> 小组件 -> Hijri Lock Style。
